Wahoo OAuth Token Generator

Instructions:

  1. Fill in your Wahoo app credentials below
  2. Click "Generate Authorization URL" to get the OAuth URL
  3. Open that URL in a new tab and authorize the app
  4. Copy the authorization code from the redirect URL
  5. Paste it below and click "Get Refresh Token"
  6. Copy the refresh token and update your GitHub secrets
  7. Prefer scripts/wahoo-auth.sh if this page hits a CORS error
